Browser extension

A shield on
every tab.

For Chrome and Edge. Works on WhatsApp Web, Instagram, YouTube, X, Facebook and any other site.

Download extension ↓

Install in a minute.

  1. Download and unzipUnzip vaanishield-extension.zip to a folder.
  2. Open extensionsGo to chrome://extensions (or edge://extensions) and switch on Developer mode.
  3. Load itClick Load unpacked and choose the unzipped folder.
  4. Pin the shieldClick the puzzle icon and pin VaaniShield to your toolbar.
  5. Use itOpen any site, click the shield, press Start listening, play the voice, then Stop & check.

The VaaniShield server must be running on this computer (start_demo.bat).
